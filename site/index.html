금은방 고객관리

고객관리 CRM

금은방의 고객·거래·세그먼트·리마인드·영업 파이프라인을 한곳에서 관리하는 웹 애플리케이션. 매장 직원이 로그인해 자기 고객만 다룹니다.

GitHub 저장소 기능 살펴보기

주요 기능

고객 관리

등록·조회·수정·삭제. 유입경로와 구매목적(복수 선택), 첫 방문일·메모까지.

거래 기록

고객별 판매·매입 이력. 품목·중량·순도·금액을 정밀하게 저장합니다.

세그먼트 검색

이름·전화 검색에 구매목적·유입경로·미방문 기간(30·90·180·365일) 필터.

대시보드

전체 고객 수, 이달 판매·매입 금액, 90일 미방문, 구매목적 분포, 최근 거래.

리마인드

다음 이벤트일 기준으로 기한 지남 · 7일 이내 · 30일 이내로 자동 분류.

영업 파이프라인

5단계 칸반 보드. 카드를 드래그하거나 이전·다음 버튼으로 단계를 옮깁니다.

기술 스택

Next.js 16 (App Router) TypeScript Supabase · PostgreSQL Supabase Auth Tailwind CSS v4 shadcn/ui zod Vitest Vercel

설계 원칙

정밀 수치금액·중량·순도는 PostgreSQL numeric 에 저장하고 앱에서는 문자열로 다뤄, 부동소수점 오차를 배제합니다.
시간대 고정모든 날짜·시각 기준은 Asia/Seoul. 순수 날짜는 date, 타임스탬프는 UTC 저장.
행 수준 보안모든 테이블에 Row Level Security 적용. 로그인한 직원은 자기 고객·거래만 조회합니다.
서버 우선기본은 Server Component. 데이터 변경은 Server Action, 인증 콜백은 Route Handler.
계산은 조회 시최근 방문일·리마인드 상태는 저장하지 않고 조회 시점에 계산합니다.
