## 실패 시 확인

| 증상 | 확인 |
| --- | --- |
| 홈 화면이 오류 카드 | RPC 가 적용됐는지 (`select public.dashboard_summary();`, `0015`/`0018`/`0021`/`0024` 마이그레이션) |
| 종합분석 화면이 오류 카드 | `select public.customer_analytics();` 로 확인, `0018`/`0019`/`0025` 마이그레이션 적용 여부 |
| "거래 수 현황"이 거래 고객 수처럼 보임(중복 거래가 안 늘어남) | `0021_dashboard_trade_counts.sql` 적용 여부 |
| "방문 목적별 고객 수" 기간 탭이 항상 0 | `0024_dashboard_purpose_periods.sql` 적용 여부 |
| 종합분석에 방문빈도·품목분포·거래수 상위 고객 카드가 안 보임 | `0025_customer_analytics_v3.sql` 적용 여부 |
| 첫 거래 등록해도 첫 거래일자가 안 바뀜 | `0023_first_trade_date_trigger.sql` 적용 여부 |
| 유입경로/방문목적 "기타"에 세부 내용 입력란이 안 뜸 | `0022_customer_other_details.sql` 적용 여부 |
| 홈 대시보드 값이 0 | 로그인 상태인지 / 샘플이 **그 사용자** 에게 들어갔는지 (`owner_id`) |
| C2·C3 금액이 다름 | 이번 달 집계인지(전체 아님) · Asia/Seoul 기준인지 · `docs/DEMO_DATA.md` §4 SQL 과 비교 |
| C5·C6 일정 건수가 다름 | 적용일 기준 상대 날짜라 **적용 후 시간이 많이 지나면** 일부 일정이 상태 구간을 넘길 수 있음 → 샘플 재적용 시 `[DEMO]` 제거 후 재실행 |
| 검색이 부분 일치로 됨 | 이름은 **정확 일치** 사양 (D3) |
| 시세 재등록 시 새 행이 안 생김 | `0017_gold_price_history.sql` 적용 여부 확인(`registered_at` 컬럼 존재해야 함) |
| 같은 날 재도달 알림이 안 뜸 | `saveGoldPrice` 의 `dedupe_key` 가 "시세 등록 건" 단위인지(날짜 단위면 구버전) |
| 샘플이 중복됨 | 재실행해도 `ON CONFLICT DO NOTHING` — 중복이면 스키마/해시 확인 |
| 다른 사용자 데이터가 보임 | RLS 정책 활성 여부, 각 RPC 가 `security invoker` 인지 |
