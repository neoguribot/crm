## 실패 시 확인

| 증상 | 확인 |
| --- | --- |
| 대시보드가 오류 카드 | `0002_dashboard_summary.sql` 적용됐는지 (`select public.dashboard_summary();`) |
| 대시보드 값이 0 | 로그인 상태인지 / 샘플이 **그 사용자** 에게 들어갔는지 (`owner_id`) |
| C2·C3 금액이 다름 | 이번 달 집계인지(전체 아님) · Asia/Seoul 기준인지 · `docs/DEMO_DATA.md` §4 SQL 과 비교 |
| C5·D8 미방문 수가 다름 | 최근 방문일 = `max(trade_date) ∨ first_visit_date` · 기준일 Asia/Seoul |
| G* 리마인드 수가 다름 | 적용일 기준 상대 날짜라 **적용 후 30일 이상 지나면** 일부 이벤트가 기한을 넘길 수 있음 → 샘플 재적용 시 `[DEMO]` 제거 후 재실행 |
| 검색이 부분 일치로 됨 | 이름은 **정확 일치** 사양 (D3) |
| 샘플이 중복됨 | 재실행해도 `ON CONFLICT DO NOTHING` — 중복이면 스키마/해시 확인 |
| 다른 사용자 데이터가 보임 | RLS 정책 활성 여부 (`0001` §7~8), `dashboard_summary` 가 `security invoker` 인지 |
